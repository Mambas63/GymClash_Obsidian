## 📂 Struktur des Vaults

Dieser Obsidian-Vault dient als zentrale Dokumentation für die Planungs-, Architektur- und Textphasen unserer Diplomarbeit:

* Jedes Teammitglied hat einen eigenen Ordner wo die Person strukturiert hochladen kann an was sie gearbeitet hat

---

## ⚙️ Workflow & Synchronisation
Dieser Vault wird über das **Obsidian Git-Plugin** vollautomatisch im Hintergrund synchronisiert. 
* Änderungen werden im Minuten-Takt automatisch gespeichert und hochgeladen (`Commit & Push`).
* Beim Starten von Obsidian werden die neuesten Änderungen der Teamkollegen automatisch heruntergeladen (`Pull`).
